# Dinner Recipe Book — GitHub Pages / Android PWA

This folder is ready to upload to a GitHub repository and publish with GitHub Pages.

## What is included

- 167 indexed cookbook recipes (Garlic Bread Pizza and Beef Wellington excluded as requested).
- 71 cookbook-exclusive recipes bundled from the supplied photographs.
- The 18 recipes in the first digitization batch retain their manually reviewed transcription.
- Remaining cookbook-exclusive recipes include OCR text plus the original page scans for verification.
- 96 public RecipeTin Eats recipes can be downloaded by the app directly to the phone and then used offline.
- Search and filters (including exact 2- and 3-ingredient filters), favorites, personal 1–10 ratings, notes, cooking history, meal photos, serving scaling, random selection, combined shopping list, sharing, and print/save-to-PDF.
- Backup and restore of personal data and downloaded website recipes.

## Publish

1. Create a new GitHub repository.
2. Upload every file and folder from this package to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
5. Open the Pages URL in Android Chrome. Tap **Sync website recipes** and allow it to finish. Then use Chrome's menu → **Install app**.

The website sync is resumable. Recipe data is saved in browser storage; export a backup from Settings periodically.


## Important data note

The 71 cookbook-photo recipes are inside the package and available immediately offline. Eighteen were manually checked; 53 are OCR drafts and retain their source scans for verification. The 96 recipes published on RecipeTin Eats are indexed in the package and are downloaded once through the app, then cached on the device for offline use. Publisher nutrition and food images are stored when the public page supplies them.
