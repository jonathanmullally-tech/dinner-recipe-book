1. Upload build_static_recipes.py and requirements.txt to the root of the dinner-recipe-book repository.
2. In GitHub choose Add file > Create new file.
3. In the filename box enter: .github/workflows/build-static-recipes.yml
4. Copy all text from WORKFLOW_CONTENT.txt into the editor and commit directly to main.
5. Open Actions and select Build static website recipe library, then Run workflow.
